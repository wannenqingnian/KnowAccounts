# 收支分析（0.7.1）

底部“分析”独立页面，支持按月与按年、前后周期切换，展示收入、消费净额、结余、支出总额、到账退款及与上期的变化。月视图展示截至所选月的最近6个月，年视图展示所选年12个月；柱状图可横向滚动，点击月份查看精确金额。

## 口径

- 数据只来自当前账本已保存且未删除、未排除统计的交易。待确认来源、草稿、期初余额不计入。
- 收入仅收入交易。支出总额仅支出交易；退款按实际到账交易日期独立汇总。
- 消费净额＝支出总额－到账退款－报销到账；结余＝收入－消费净额。
- 转账、信用卡/花呗/贷款本金还款与余额调整不计入收支。待报销标记仍计支出；0.13.0 起报销到账按到账日期抵扣消费净额与预算支出，不计普通收入。
- 跨月/年退款和报销落在到账期间，可能使消费净额为负，这是预期行为。
- 分类环图/百分比按退款/报销前支出或总收入计算，不用负净额绘制比例；退款在摘要单列。不自动按原消费时间回溯改写统计。
- 月度柱状图绿色收入、橙色退款前支出；月份明细同时提供退款、净额、结余。
- 变化率=(本期－上期)/abs(上期)。上期为零时显示“上期为零”，两期皆零显示持平，不虚构增长率。
- 日期范围起点包含、终点不包含；人民币以整数分汇总，只在图形高度和比例展示时换算浮点数。

退款流水查询补齐原交易分类名称，不改交易分录或Schema。当前分析与已有流水共享账本一致性快照；金额超多时会继承当前全量流水加载的性能边界，后续应改为分页与数据库聚合。

测试覆盖日期边界、闰年、跨期退款、退款超过当期支出、删除、排除统计、转账、调整、零/负基线、退款分类、按年、交互明细和切换账本隔离。界面截图使用隔离的演示数据，不写入用户账本。

## 扩展图表与标签

支持全部数据及自定义起止日期。收支图可切换退款前支出、收入与结余，负结余柱显示在零轴下；月份点击查看精确金额。超120个月仅图表/月度表显示最近120个月，摘要仍包括完整范围。

日历热力按月/年展示每日金额，支持收入、支出和结余；年视图可选择范围内年份，点击日期查看当日收支流水。负结余用红色，无数据为灰色。

资产曲线来自账户期初余额及所有实际分录，包含排除消费统计的交易、排除已删除交易；支持全部账户净余额或单个账户。转账的出入分录同时计入，不能把信用卡还款误计为净资产增加。此回溯不含未录入的投资估值；调整期初余额会回溯影响历史。

分类环图/排行可切换收入/支出和一级/二级；点击排行查看该组实际交易。月度表包含收入、支出、退款、结余。

记账表单新增标签：逗号/空格分隔、去重、每个最多20字、每笔最多10个。多标签金额以整数分平均分摊，余下的分按标签顺序分配，不重复统计；无标签归“未标记”，可隐藏。标签排行点击查看关联交易。标签随编辑、删除恢复和密码备份保存，Schema v4及旧版无标签升级/恢复已验证。

年度总结显示全年收入、净支出、结余、退款、交易笔数、记账天数、全年日均净支出、储蓄率及支出最高月份；收入为零时不给出虚构储蓄率。年度总结独立使用当前所选年份。

## 0.7.1 布局调整

收入、消费净额、结余合并为一张三列摘要卡片，大字体时自动改为三行。支出/退款/笔数保留在可展开统计说明，图表更靠近首屏；不改变计算口径。430×932界面测试验证摘要低于140像素且趋势标题位于首屏，系统2倍字体验证无布局溢出。

## 0.13.0

摘要及年度总结单列报销到账，月份表的“退款/报销”为两者合计；每日结余包含报销到账。分类/标签占比仍是抵扣前消费结构，净额在摘要中体现。开启金额隐私模式后整个分析金额与图表隐藏，关闭后恢复；账目计算不受开关影响。
