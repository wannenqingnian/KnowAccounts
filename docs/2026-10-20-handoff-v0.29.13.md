# 知账 0.29.13 交接说明

## 功能与使用

- 诊断中心新增“允许日志记录敏感信息”，默认关闭，且须先开启日志记录。开启后新采集的金额、商户、账户按实际提取结果显示；不会恢复此前已脱敏的内容。
- 关闭敏感信息开关会重写本机已有自动记账日志，删除金额、脱敏商户和账户。历史导出文件不受影响。日志仍限制 48 小时 / 400 条；不保存整个支付页面、聊天内容、密码或令牌。
- 无障碍、截图 OCR、未匹配和重复跳过阶段携带已提取的字段摘要。没有读取到的字段不会伪造；日志中的账户摘要不等于已成功匹配账本账户。
- 记账表单“更多信息 → 添加记账地点”调用系统定位；只请求前台权限，一次获取，最长等待 20 秒，不进行后台跟踪。
- 当前地点为经纬度与精度，不是街道地址。开启后需要等待定位完成，或关闭地点选项再保存；权限拒绝、定位失败不会丢失已填表单。
- 地点保存为备注中的 `📍记账地点：` 独立行，不改数据库结构。编辑账单时保留，关闭地点可移除；模板新建不复用旧地点。现有备份和导出随备注保留地点。

## 修改范围

- Android：`PaymentTrace` / `PaymentTracePolicy` 管理敏感信息设置和历史脱敏；`PaymentCaptureGuard` 提取诊断字段；采集服务与后台队列补充摘要。
- Flutter：诊断模型、桥接接口和诊断中心开关/展示；`transaction_location.dart` 调用系统定位，记账表单写入备注。
- 配置：新增 `geolocator` 依赖及锁文件；Android 前台粗略/精确定位权限、iOS 使用期间定位说明。
- 未改交易解析、账户匹配、去重、余额、统计、状态管理或数据库接口。

| 证据 | 结果 | 对应结论与路径 |
| --- | --- | --- |
| `flutter analyze --no-pub` | 无问题 | Flutter 表单、诊断页与桥接静态检查通过 |
| `flutter test test/automation_diagnostics_test.dart test/transaction_location_test.dart` | 14 项通过 | 默认脱敏 / 显式开启 / 展开详情 / 小屏日志页；定位授权 / 拒绝 / 禁用 / 单次读取 / 备注往返 |

调用路径：诊断开关 → Flutter 桥接 → 原生设置与历史脱敏 → 诊断报告；地点开关 → 系统权限 → 单次定位 → 备注 → 原有保存流程。

## 发布与待验收

- 版本 `0.29.13+79`，目标标签 `v0.29.13`；继续使用既有 Android ARM64 构建、固定签名与正式 Release 流程。
- 发布流程新增本次 Flutter 回归与 Android 字段提取、脱敏测试；任一步失败即停止构建发布。
- Windows 测试批量运行曾出现 `did not complete`；诊断与定位 14 项串行通过，OCR 人工确认单独通过，合并执行时该旧 OCR 测试仍偶发未完成。CI 分进程执行这三个测试文件，诊断页使用 `--concurrency=1`。
- 未做真机定位、实际支付页面、权限设置切换与升级覆盖安装验收；Windows 环境未验证 iOS 构建。
- 打开敏感日志后，日志文件可能包含财务隐私。定位坐标写入备注后也会进入账单导出与备份。
- Android 原有页面识别测试中有两项旧断言与现行规则不一致，本次不修改这些无关断言。
