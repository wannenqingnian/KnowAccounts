# 银行、信用平台和还款日期

## 0.3.0 账户能力

新增信用支付、贷款/现金借款两类账户，支持其他/自定义平台。模板用于本地记账，不代表平台登录、授信、余额查询或账单 API 接入。

| 类型 | 模板 |
| --- | --- |
| 信用支付 | 花呗、京东白条、微信分付、抖音月付、美团月付、招联信用付 |
| 贷款 | 借呗、京东金条、微粒贷、度小满有钱花、招联好期贷、美团借钱、抖音放心借 |

银行和信用卡提供 22 家模板：工商、农业、中国、建设、交通、邮储、招商、中信、兴业、浦发、民生、光大、平安、广发、华夏、浙商、渤海、北京、上海、宁波、江苏、杭州，另支持自定义银行。不会自动创建用户未使用的平台账户或预填授信额度、利率和还款日。

## 卡号保存

可输入4位尾号或13～19位完整卡号，允许空格及分隔符，保留前导零。完整卡号通过系统安全存储保存，SQLite 仅保存尾号及随机引用。长度检查不表示发卡行、卡片有效性或持卡人验证；银行模板由用户选择。

账户、流水和确认表单只显示名称/尾号。“查看卡号”弹窗初始隐藏，主动点击才显示完整号码，30秒后自动隐藏。尚未增加生物识别门禁或截图屏蔽。

Android 使用加密 SharedPreferences，iOS 使用 Keychain。Android 系统自动备份关闭。App 密码加密备份包含完整卡号，整个载荷受 AES-GCM 保护；恢复先校验卡号/尾号一致性，再以新引用写入目标设备安全存储。安全存储或 SQLite 写入失败时不替换原账本。恢复后旧的安全存储记录可能暂时保留，后续增加清理。

## 还款日与分录

信用卡、信用支付和贷款支持每月1～31日及指定到期日期。短月份的29～31日按月末计算；每月日期展示当前或下一次还款日期。指定日期优先并原样保留，包括已过期日期，需用户自行更新。

还款日按实际账单设置，不把所有产品强制设为固定月付日。当前只在账户页展示日期，没有系统通知提醒、分期计划或应还金额计算。

- 新增负债账户的“当前欠款”填正数，内部为负余额。
- 信用消费记支出，增加欠款。
- “记录还款”打开资金账户→负债账户的转账表单，本金不重复算消费。
- 借款到账用贷款账户→资金账户转账，不算收入。
- 利息和手续费单独记支出，混合本金/利息不自动拆分。

授信额度不计入资产；列表欠款为本地有效分录的负净余额，不代表平台账单的实际应还金额。

## 智能识别

“支付宝花呗”优先匹配花呗账户；未添加对应账户时保持未确定。模板账户改名后仍用 provider_id 匹配。银行名加尾号可区分多张卡，多个候选仍要求核对。贷款、借款、还款描述走手动转账，不自动算普通收入。

Schema v2 给 accounts 增加 provider_id、repayment_day、due_date、bank_id、card_last4、card_secret_id。v1→v2 只增加可空列，不改历史金额和分录；0.1/0.2 备份可恢复。v2 备份不能在旧版 App 恢复。

## 0.5.0 编辑账户

每个账户卡片都有“编辑账户”，默认现金、银行卡、微信、支付宝也支持。可修改名称、类型、银行/信用平台、卡号或尾号、当前余额和还款日；不会重新创建账户或改变关联交易ID。类型变为非银行账户时清除银行卡元数据，变为非负债账户时清除还款信息。

编辑时“当前余额”显示带符号净余额：欠款填负数。修改余额在事务中重新计算有效分录，调整期初余额为“目标余额减有效分录合计”；保留流水，收入/支出统计不变。它用于纠正账户余额，不代表新增收支。以后删除/恢复已有交易仍会改变余额。

编辑卡号留空会保留已有卡号，不会自动读取和显示完整卡号。输入新完整卡号或尾号可以替换，也可明确勾选清除。先写新安全记录，再原子更新账户；失败时保留原记录、清理新记录。修改提交后清理无账户引用的旧卡号；系统安全存储清理失败时可能留下不可访问的旧密钥，后续提供统一清理。

账户编辑测试覆盖默认账户、余额与统计、稳定ID、重名及账本隔离、尾号/完整卡号保留替换清除、银行与信用类型转换、SQL或安全存储失败回滚。Schema保持v3，无需额外迁移。
