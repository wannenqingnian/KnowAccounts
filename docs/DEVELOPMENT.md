# 知账开发计划与功能差异

更新基线：`0.29.6+72`，SQLite Schema v16。

本文是当前项目唯一的功能开发总表，合并了：

- 《智能记账 App 功能总览与开发计划》的非云端目标；
- 当前源码、数据库、页面入口和自动测试的实际状态；
- 一木记账 6.1.6 静态对照中仍未完成的能力；
- 现阶段 Android 优先、iOS 最后实施的顺序。

状态含义：`已完成` 表示源码和自动测试已存在；`部分完成` 表示已有可用流程但尚未达到完整目标；`待开发` 表示当前没有完整实现；`暂缓` 表示本阶段明确不做。

## 一、范围与原则

1. 坚持本地优先。识别、解析、学习、去重和报表默认在设备内完成。
2. 不为了提高自动入账率牺牲准确性。退款、转账、借贷、亲情卡和字段冲突必须保守处理。
3. 自动记账以统一字段、证据、置信度和幂等规则为核心，不按某一张截图硬编码整页模板。
4. 一木记账仅用于产品行为与静态适配思路对照；知账保持独立实现，不复制品牌、素材或反编译源代码。
5. 账号体系、云 OCR、云 ASR、云端 AI、实时同步和跨设备并发合并暂缓。现有 WebDAV 加密整库备份继续保留，但不扩展为实时同步平台。

- 秒级交易时间、编辑、软删除、5 秒撤销、回收站恢复/多选彻底删除和自动清理。
- 多账本、多币种、历史汇率、跨币种转账和人民币本位币统计。
- 两级分类、图标、模板、分享、排序、隐藏和归档。
- 账户新增、编辑、归档、完整卡号安全存储、信用账户和还款日期。
- 记账模板、周期收支、周期转账、周期投资、后台定时、提醒、跳过、执行历史和失败重试。

### 2.2 智能输入与自动记账

- 一句话记账、Android 本地 SenseVoiceSmall 语音记账和 Silero VAD。
- Android PP-OCRv6 tiny/small/medium 本地截图识别、图片导入、通知栏入口、快捷设置磁贴和悬浮核对表单。
- Android 通知监听、无障碍增强、跨事件页面会话和 23 个支付来源配置。
- 微信、支付宝、云闪付及 Excel/CSV 专用账单导入、字段映射、预览、退款关联和订单去重。
- 待确认草稿持久化、批量确认安全账单、批量忽略、忽略恢复与清理。
- 疑似重复标记，由用户确认是否仍保存；同一草稿确认幂等。
- 自动修正规则支持商户、收支类型、来源、金额范围、付款方式、跨账本目标、命中记录、批量修正和撤销学习。
- 亲情卡发送方/使用方、额度、真实扣款账户、事件审核、退款/撤销及双方独立分析报表。

### 2.3 财务管理与分析

- 月度、季度、年度和自定义预算；总预算、分类预算、结转、超支提醒、明细、隐藏和归档。
- 股票、基金、定期存款、房贷、分期、借出/收回及信用卡账期核对。

- 账单分组、拆分和 AA 均分。
- 月/年/自定义分析、分类和标签排行、日历热力、月度趋势、账户余额曲线和年度总结。
- 亲情卡资金方实际代付与消费方受资助消费分开统计。

### 2.4 管理、外观与本地数据

- 浅色/深色、主题色、背景、字体、字号、图标风格和主题分享。
- 管理页日志中心、日志开关、可理解的原因/结果/建议、筛选、复制、导出和清空。
- Android 动态快捷方式、固定桌面快捷方式和快捷记账小组件。
- AES-256-GCM 加密备份、历史版本恢复校验和 WebDAV 加密整库上传/下载。
- WebDAV 凭据、备份密码和完整卡号使用系统安全存储。

## 三、通用与 Android 待完成计划

### P0：正确性与统一数据链路

#### 3.1 统一置信度引擎｜部分完成

`0.29.1` 已升级为 `confidence-rule-v2`：OCR、通知、无障碍、语音和一句话草稿统一输出金额、商户、账户、时间、完成状态、分类、方向和来源八个字段分数，以及整单高/中/低决策。结果包含引擎版本、模型版本、来源、实际阈值、校准版本和中文理由，并随草稿持久化。OCR 原始分数仅作为文字质量证据，不直接当作正确概率。

需要完成：

- [x] 将 OCR/ASR 质量、金额唯一性、商户匹配、账户匹配、时间、完成状态和来源可信度组合为字段置信度与整单置信度。
- [x] 保存置信度版本、模型版本、来源和判定理由，避免规则升级后无法追溯。
- [x] 形成明确策略：高置信自动入账、中置信待审核、低置信仅允许人工填写；复杂交易继续强制审核。
- [x] 提供不含金额、商户、账户和原文的 JSONL 标注格式，并可按来源、模型版本重复回放。
- [x] 统计自动入账数、误记数、审核率、误记率及 Wilson 95% 上界；安全门槛未通过时拒绝生成配置。
- [x] 校准配置随应用打包，运行时验证来源、模型、样本量和误记率；空包、损坏包或来源不匹配时回退保守规则。
- [ ] 收集真实脱敏标注样本并生成首批可部署参数；在此之前配置包保持为空，所有结果保持 `calibrated=false`。

验收：同一批标注样本可重复得到相同结果；自动入账误记率有可统计指标；日志能解释每个字段为何确定或不确定。

实现与边界见[统一置信度引擎](CONFIDENCE.md)。

#### 3.2 跨来源统一去重与合并｜已完成第一阶段

现有重放幂等、同日候选、导入订单号和亲情卡证据合并继续保留，补齐：

- 通知、无障碍、OCR、语音、CSV/Excel 和手动补账之间的统一指纹。
- 优先按订单号合并；无订单号时按金额、标准化商户、时间窗口、账户和方向生成候选。
- 不以金额单独自动合并；冲突时显示证据差异并由用户决定。
- 为普通账单提供“合并为同一笔”和撤销合并能力。

0.29.3 已完成上述第一阶段：统一证据表覆盖通知、无障碍、OCR、语音、CSV/Excel 与手动补账；订单号以平台隔离的哈希优先匹配，无订单号时仅生成“金额＋标准化商户＋同日时间窗口＋账户＋方向”候选。金额单独不产生候选，所有合并均需人工确认，字段冲突逐项展示；普通流水可合并并撤销。原有采集重放幂等、导入备注标记、同日候选和亲情卡专用证据链保持不变。

#### 3.3 所有入口统一经过解析与学习管线｜已完成

OCR、语音、通知和一句话记账继续通过 `TransactionParser` 生成草稿；CSV/Excel 批量导入和手动表单改由统一的结构化提交入口处理。最终链路为：

`RawTransaction → 来源字段解析 → TransactionParser → 自动修正 → 去重/置信度 → 草稿或入账 → LearningEvent`

手动记账跳过自然语言解析，但仍生成结构化草稿快照，并进入自动修正、统一置信度、订单号/语义去重、来源证据、规则学习和审计步骤。疑似重复的手动账单必须二次确认；导入候选计入重复并跳过。草稿创建、确认、忽略、手动/导入入账均写入隐私化 `LearningEvent`，不在事件表保存支付原文，且随加密备份迁移。

#### 3.4 待处理账单批量工具｜已完成

- 增加批量修改账户、分类、标签和账本。
- 增加重复候选成组审核、普通账单合并及合并撤销。
- 批量处理前显示预计修改和跳过原因，失败时保证事务回滚。
- 保留已有批量确认、批量忽略和忽略恢复。

0.29.4 已补齐：待处理页长按多选后可统一修改账户、分类、标签和目标账本；执行前逐笔显示预计变化与跳过原因，亲情卡、字段不兼容、已处理和无变化项目不会被误改。批量确认同样先区分可安全入账与需逐笔核对项目，批量忽略显示可恢复提示。批量修改、确认和忽略均使用数据库事务，任一写入失败时整批回滚。新增“重复候选”页，按订单号或金额、标准化商户、时间窗口、账户和方向形成分组，由用户选择保留候选；若已有正式账单可整组忽略。普通流水已有的“合并为同一笔”和撤销合并继续保留。

### P1：智能学习与财务闭环

#### 3.5 完整 LearningEvent 与商户知识库｜已完成

- 分别记录商户、分类、账户、标签和账本的“识别值→用户最终值”。
- 将当前静态商户词典升级为本地可维护的商户、别名、默认分类和来源映射表。
- 增加规则建议流程，允许接受、编辑或拒绝，避免一次误改直接污染长期规则。
- 增加时间段、星期、来源账户等规则条件。
- 用本地历史统计提供个性化分类候选；本地小模型作为后续可选项，不阻塞规则系统。

0.29.5 已补齐：每次确认分别记录商户、分类、账户、标签和账本的识别值与最终值，但不会立刻改写生效规则。系统先在本地影子学习，至少累计 3 次且一致率达到 80% 才生成待审核建议；用户可接受、编辑或拒绝，拒绝后抑制同类重复建议。悬浮表单也可显式勾选“建议沿用”，但仍只生成待审核建议。已生效规则不会被新样本静默覆盖。

商户知识库支持维护标准商户名、多个别名、默认分类及来源映射；分类缺失时先使用知识库，再使用当前账本的历史统计候选。规则条件新增时间段、星期和来源账户，来源账户可跨账本选择。确认弹窗允许切换目标账本，并同步刷新该账本的账户与分类；亲情卡账单保持在所属账本，避免破坏额度和扣款关系。本地小模型仍作为后续可选增强，不是规则和历史学习链路的前置依赖。

## 四、一木记账对比合并结果

### 4.1 已经补齐，不再列为缺失

- 包名白名单、Activity/页面守卫、节点数量上限和跨事件页面会话。
- 微信、支付宝及一木静态分派可确认的京东、美团、淘宝、拼多多、抖音、快手、本地生活和金融钱包应用族。
- 支付、转账、收款、红包、充值/提现及来源专属金额、商户、账户、时间字段。
- 离开支付页清理会话、OCR 期间暂停新会话、成功后抑制事件风暴。
- 快捷 OCR 不进入主应用，直接在当前页面截图、识别并弹出悬浮核对表单。
- 悬浮表单、分类搜索/新增、重复标记、通知栏动作、桌面快捷方式和基础小组件。
- 模板、周期计划、预算、资产负债、标签、回收站、批量导入、自动修正和亲情卡。

### 4.2 对比后仍需补齐

1. **真实运行样本适配**：静态分析只能证明分支存在，不能证明不同机型、字体、地区和支付软件新版本均能识别。每个来源需要成功、退款、失败、转账和页面切换样本验收。
2. **适配器版本化**：为包名、Activity、完成状态和字段词表增加本地版本号、兼容范围和回归夹具；适配变化随应用版本发布，不依赖云端下发。
3. **真实样本置信度校准**：所有入口现已进入统一置信度、订单候选和冲突解释体系；仍需用真实脱敏样本生成首批安全校准参数。
4. **批量审核效率**：补齐批量改分类/账户/标签、重复成组处理和普通账单合并。
5. **订阅、存钱目标和今日可花**：属于一木类成熟记账产品常见的财务闭环，当前知账只有周期计划和预算基础。
6. **更多桌面小组件**：当前快捷四按钮已完成，仍缺今日消费、预算、待处理和模板直达等信息型组件。
7. **本地应用锁与隐私保护**：补齐生物识别、敏感页面截图保护和本地数据库加密。

保留差异：知账不会为了表面一致而放宽安全策略。退款、借贷、还款、账户间转账、亲情卡角色冲突及低置信截图仍必须进入人工核对，不能静默当作普通收支。

详细静态证据继续保存在 [一木记账自动记账静态对照](REA_YIMU_AUTOMATION.md)，自动记账当前行为见 [自动记账说明](AUTOMATION.md)。

## 五、暂缓的云端范围

以下内容不进入当前排期：

- 账号注册、登录和找回。
- 自建服务器、云数据库和记录级实时同步。
- 多设备并发写入、冲突合并和在线共享账本成员权限。
- 云 OCR、云 ASR、云端大模型和服务端商户画像。
- 云端自动备份历史与密钥托管。

WebDAV 继续定位为用户自行配置的加密整库备份/恢复，不承诺记录级实时同步。家庭、情侣和旅行账本可以先作为本地账本使用；管理员、成员、只读权限随共享账本云端设计一并暂缓。

| M3 财务闭环 | 订阅发现、今日可花、存钱目标、全口径净资产 | 统计口径与退款/报销/外币保持一致 |
| M4 本地安全 | 应用锁、二次认证、截图保护、数据库加密评估 | 升级可回滚，敏感数据不出现在明文快照 |
| M5 Android 发布 | 真机矩阵、性能、正式签名与隐私文档 | Release 可安装升级，核心支付样本验收通过 |
| M6 iOS | 按本文最后一节实施 | iOS 本地输入、分享和快捷入口可独立验收 |

## 七、验收规则

- 每个新功能必须包含账本隔离、退款/删除、备份恢复和异常中断测试。
- 自动记账适配至少覆盖成功、失败、处理中、退款、转账、页面退出和重复事件。
- 涉及余额的功能必须验证账户分录守恒；涉及分析的功能必须验证跨月退款和报销口径。
- UI 必须在小屏、系统大字体、键盘弹出和金额隐私模式下可用。
- 文档中的“已完成”必须能定位到源码、页面入口和自动测试；仅有模型类或占位页面不能标为完成。

## 八、iOS 开发计划（最后实施）

iOS 项目目前只有 Flutter Runner 基础壳，以下内容统一放在 Android 和通用本地功能稳定之后。

### iOS-1 基础可用性

- 使用 macOS/Xcode 完成构建、签名、安装、升级和 SQLite 迁移验证。
- 验证文件选择器、图片附件、加密备份、Keychain、主题、大字体和中文输入。
- 补齐相机/相册、麦克风、语音识别等隐私声明和拒绝权限流程。

### iOS-2 本地 OCR 与分享入口

- 使用 Apple Vision 或验证后的跨平台 PP-OCR 实现图片/截图 OCR。
- 增加 Share Extension，从照片、截图和文本分享生成待确认草稿。
- Share Extension 只保存最小必要的脱敏交接数据，主应用完成数据库写入和核对。
- 复用 Android 已有的统一解析、去重、置信度、退款关联和自动修正规则。

### iOS-3 本地语音记账

- 评估 SenseVoice/sherpa-onnx 的 iOS 体积、启动速度和内存；不可接受时使用系统离线语音能力。
- 保持“立即录音、后台加载模型、用户点击完成”的交互，并支持可选静音自动结束。
- 原始录音默认不落盘、不上传，识别结果进入统一草稿流程。

### iOS-4 App Intents 与 Siri

- 提供手动记账、一句话记账、语音记账和图片识别 App Intent。
- 支持 Siri/快捷指令传入金额、商户、分类、账户和备注；字段不完整时进入核对页。
- 增加桌面小组件、锁屏小组件和快捷操作，同时遵守金额隐私模式。

### iOS-5 验收

- 真机覆盖当前支持的最低 iOS 与最新 iOS。
- 验证 Extension 与主应用并发、锁屏、后台终止、低存储和模型未下载场景。
- iOS 不提供 Android 式通知读取或无障碍页面扫描；自动化入口以分享、快捷指令、Siri 和用户主动选择图片为边界。
