# 知账 · Smart Ledger

离线优先的智能记账 App，目前交付 `0.28.0` 开发测试版。Android 已接入按需下载的飞桨 PP-OCR 与 SenseVoiceSmall 本地语音识别。使用 Flutter、Riverpod 和 SQLite/Drift，生成 Android、iOS、Linux 项目。首次启动仅创建空账本、默认账户和分类，不插入演示交易。

## 安装包下载

当前只提供 ARM64 Release 测试包，支持 Android 7.0 及以上。每个 APK 只包含一种 CPU 架构，现代手机通常选 arm64-v8a。仍使用 Android Debug 开发签名，尚未进行真机安装验证。安装包附有 SHA-256 校验文件，不提交到源码历史中。GitHub 上传目前被连接权限限制拒绝，尚无可用 GitHub Release。

## 已实现

- 亲情卡账户：统一管理微信亲属卡和支付宝亲情卡/亲情号，分别保存发送方额度与使用方额度，并区分本机是发送方还是使用方。额度仅用于统计，不计入资产余额；发送方可绑定实际扣款账户和默认分类，使用方不会自动扣减本人账户。自动记账只接受“亲属卡/亲情卡/亲情号 + 已完成交易”的强证据，排除支付宝小荷包和普通代付；通知、无障碍与OCR按订单号合并去重，首次识别默认进入人工核对。
- 周期计划使用 Android 系统闹钟在应用未打开时唤醒短时 Dart 后台引擎；支持到期结果提醒、结束日期、最大执行次数、跳过本期、执行历史以及按 15 分钟起步指数退避的失败重试。重启设备和升级应用后会恢复下一次计划。
- 独立标签管理：新增、改名、合并、隐藏、查看标签账单，并可按商户/备注关键词自动添加智能标签。分类管理新增图标库、日常/家庭/旅行模板及 JSON 复制分享与导入。

- 自动修正管理：人工确认带商户的普通收支后，本地自动学习所选账户、分类和标签；后续 OCR、支付通知、语音/一句话记账及待确认账单会优先套用。支持精确/包含匹配、收入/支出隔离、优先级、搜索、编辑、启停和删除；退款与转账不参与，归档账户或分类会自动停用关联规则。
- 可核对的资产与负债管理：股票/基金买入卖出、加权持仓成本、收益率和净值历史；定期存取与利息；房贷/分期还款计划和逐期明细；借出/收回流水与未收余额；信用卡账期自动匹配账本流水并逐笔核对。旧版手工资产资料会保留为期初值。
- 多币种账户：可维护币种代码、名称、符号、小数精度及兑人民币汇率；交易同时保存原币金额和人民币本位币金额，跨币种转账保存目标原币金额，历史交易使用入账时汇率，不因后续改汇率而重算。
- 账单拆分、AA与分组：从单条流水操作中按参与人拆分、精确均分余数、标记结清；账单可加入旅行、聚餐等自定义分组。待确认账单支持长按多选、安全批量确认或批量忽略，忽略记录可恢复或清理。
- 外观与主题：浅色/深色/跟随系统、主题色、页面背景、系统/衬线/等宽字体、80%～140%字号和图标风格；支持复制及导入带版本校验的主题分享码。
- WebDAV 账号与加密同步：WebDAV 地址、账号、密码和备份密码仅保存在设备安全存储；上传前进行 AES-256-GCM 本地加密，支持多设备恢复及 ETag 冲突保护。使用独立远端路径可共享账本，成员读写权限由 WebDAV 服务端账号和目录 ACL 控制。

- Android 本地语音记账：管理页主动下载 SenseVoiceSmall INT8 与 Silero VAD，模型不内置进 APK、不自动下载；点击后立即开始录音并在后台并行加载模型，冷启动期间语音保存在内存缓冲区。默认由用户点击“完成录音”，也可单独开启1～10秒可调的静音自动结束，或设置5～300秒最长录音时长；录音不保存、不上传。
- 0.16.1 修复 Release 混淆破坏 sherpa JNI 配置字段的问题；首次使用先预热模型，明确提示预热完成后再说话，并增加模型自检及麦克风源回退。
- 语音文字经过记账领域同音词纠正、中文金额解析及统一 `TransactionParser`，自动生成持久化草稿；未下载模型时可由用户明确选择手机系统语音作为临时兜底。详见[语音记账说明](docs/SPEECH.md)。

- 报销管理：关联原支出、部分/多次到账、待报销/部分报销/已报销状态；退款与报销共同校验累计上限，按到账日期冲减消费净额，不计普通收入。
- 管理页提供支付宝、微信、云闪付和 Excel/CSV 专用批量导入：自动识别 UTF-8/GBK、账单表头与常用字段，可人工调整列映射、预览及勾选记录；订单标识防重复导入，部分/全额退款会关联原消费并按实际退款金额冲减消费。
- 图片附件：每笔最多5张PNG/JPEG、每张4 MB，支持新增、预览、移除、独立管理；随账目软删除/恢复及全账本加密备份保留。
- 金额隐私模式：总览、流水、账户、草稿、报销展示金额统一隐藏，分析图表隐藏；开关跨重启及备份持久化。编辑表单、备注原文与主动查看图片仍可见内容。见[MVP补齐说明](docs/MVP_COMPLETION.md)。
- 手机端总览和流水采用紧凑布局：压缩卡片留白、筛选项保持单行滚动；账单左滑会同时露出“编辑”和“删除”按钮，点击账单仍可使用退款、报销和附件等完整操作，删除保留5秒撤销。
- 手机端账户页采用紧凑余额摘要和单卡片账户列表，每个账户只占一行；左滑显示编辑/归档，点击账户可查看卡号或记录还款。主界面加号在按钮附近展开浮动菜单，集中提供手动、语音、一句话和OCR截图记账。

## 运行

需要 Flutter stable 和目标平台工具链。当前开发环境使用 Flutter 3.47.6 / Dart 3.13.5。

```bash
flutter pub get
flutter run -d <设备ID>
```

Android 需要 Android SDK；iOS 需要 macOS、Xcode 和签名配置。Linux 桌面需要 clang、CMake、Ninja、GTK 3 和 libsecret 开发库。

```bash
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
python3 tool/verify_ocr_jni_apk.py build/app/outputs/flutter-apk/app-release.apk
python3 tool/verify_automation_apk.py build/app/outputs/flutter-apk/app-release.apk --aapt "$ANDROID_HOME/build-tools/36.0.0/aapt"
# 在 macOS 上执行：
flutter build ios --no-codesign
```

当前工作区 Flutter 路径为 `/tmp/flutter-sdk/bin/flutter`，不作为项目依赖提交。Android SDK、JDK 与 NDK 已安装；当前 APK 仅构建 arm64-v8a，并校验签名。尚未进行真机安装验证。工具链配置见 [Android 构建说明](docs/ANDROID_BUILD.md)。

执行环境尚未安装 Linux 桌面构建工具，未生成桌面可执行文件。此前已通过 Linux 目标 Dart 资源包编译：

```bash
flutter build bundle --target-platform linux-x64 --debug
```

该资源包不是可安装应用。

在仅安装了 `libsqlite3.so.0`、没有开发链接的 Linux 环境中，测试可以使用临时链接：

```bash
mkdir -p /tmp/smart-ledger-native
ln -sf /usr/lib/x86_64-linux-gnu/libsqlite3.so.0 /tmp/smart-ledger-native/libsqlite3.so
LD_LIBRARY_PATH=/tmp/smart-ledger-native flutter test
```

## 备份说明

备份文件扩展名为 `.slbackup`。使用 PBKDF2-HMAC-SHA256（210,000 次）从用户密码派生密钥，再使用 AES-256-GCM 加密，每次导出生成独立随机盐和 nonce。密码至少 8 个字符。手动导出不保存密码；启用 WebDAV 后，备份密码和 WebDAV 凭据保存在设备系统安全存储，不写入 SQLite 或远端明文。

导出在数据库事务内读取一致性逻辑快照。恢复先在临时数据库中校验，再通过事务替换现有数据；恢复覆盖所有账本，并保留当前设备标识。支持 v1～v12 备份恢复到当前 v12，包含来源、草稿、确认关联、附件、模板、周期计划与执行历史、标签、币种、资产、账单分组、拆分、自动修正规则及预算。WebDAV 提供加密整库上传与恢复，但不提供密钥找回或记录级双向合并。

本地 SQLite 当前未整体加密，导出的备份文件使用密码加密。完整卡号单独保存在系统安全存储，不以明文写入 SQLite；加密备份也包含完整卡号。应用尚处开发阶段，建议使用测试数据。

## 项目结构

```text
lib/
  core/database/       SQLite Schema 与数据库初始化
  domain/              核心模型、金额和日期约定
  data/                Repository、交易校验、分录和查询
  features/            总览、流水、账户、收支分析和管理
  automation/          Android自动记账、快捷磁贴与通知栏动作交接
  speech/              按需模型管理、语音识别与领域纠错
  finance/             整数金额收支聚合与统计口径
  backup/              加密备份及恢复验证
  import/              支付平台账单、Excel/CSV解析、映射、退款关联与批量导入
  transaction/parser/  来源、草稿、中文金额与统一交易解析
  merchant/            商户别名标准化
  app_state.dart       Riverpod 状态与一致性读取
  main.dart            启动、中文本地化和主题
```

数据库采用 Drift 的参数化 SQL API，目前不需要生成 `.g.dart` 文件。Schema 版本为 12，保留 v1～v11 升级与旧版备份恢复；v12 增加周期执行历史、结束与重试状态、标签定义和分类图标。银行/信用账户边界和检索依据见 [账户说明](docs/ACCOUNTS.md)。

识别时保存原始来源、采集时间和解析快照；待确认箱使用原采集时间和当前账户/分类重新解析，避免相对日期漂移和已归档选项。支持核对、取消后继续、忽略；忽略的原文仍保留。长数字编号在识别和持久化时仅保留尾号，来源原文也随密码备份加密。当前 Android OCR、本地语音、通知与无障碍来源已接入；尚无校准置信度概率或订单号级跨来源交易合并。具体规则见 [草稿与待确认箱](docs/DRAFTS.md)、[OCR模型与识别](docs/OCR.md) 和 [语音记账](docs/SPEECH.md)。
